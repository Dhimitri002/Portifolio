## 🚀 Como Executar Localmente

### Opção 1: Abrir diretamente no navegador
Basta abrir o arquivo `index.html` em qualquer navegador moderno. Graças aos fallbacks embutidos em `js/data.js`, todo o site é carregado perfeitamente mesmo sem servidor local.

### Opção 2: Servidor local simples
```bash
# Com Python
python -m http.server 8000

# Com Node (npx)
npx serve .
```
Acesse em: `http://localhost:8000`

---

## 🌐 Deploy no GitHub Pages

1. Faça o commit de todos os arquivos na branch `main`.
2. No repositório GitHub (`Dhimitri002/Portifolio`), acesse **Settings** > **Pages**.
3. Em **Branch**, selecione `main` e a pasta `/ (root)`.
4. Clique em **Save**. O site estará disponível em `https://dhimitri002.github.io/Portifolio`.
